# 🎓 Student Grade Analyzer

A beginner-friendly Python project that analyzes students' academic performance by calculating total marks, percentage, grade, and subject-wise performance.

## 📌 Project Overview

The Student Grade Analyzer is a Python-based project developed to simplify the process of calculating and analyzing a student's academic results.

It calculates total marks and percentage, assigns a grade, and identifies the highest- and lowest-scoring subjects.

## 🎯 Objective

The objective of this project is to apply basic Python programming concepts to solve a real-world problem related to academic performance analysis.

## 🛠️ Technologies Used

- Python
- Google Colab
- Python Dictionaries
- Conditional Statements
- Built-in Functions

## ✨ Features

- Accepts the student's name
- Records marks in five subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade based on performance
- Identifies the highest-scoring subject
- Identifies the lowest-scoring subject
- Displays a clear academic performance report

## 📚 Subjects Analyzed

- Mathematics
- Physics
- Chemistry
- Hindi
- English

## ⚙️ How It Works

1. The program collects the student's name.
2. It takes marks for five subjects.
3. The marks are stored in a Python dictionary.
4. The program calculates the total marks and percentage.
5. Conditional statements determine the student's grade.
6. Built-in functions identify the highest- and lowest-scoring subjects.
7. The final performance report is displayed.
